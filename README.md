# Quiet Runtime

Practical software for local AI, media, and automation.

I build tools that connect models, browsers, desktop apps, and
self-hosted services, with a focus on useful interfaces and reliable operation.

### Areas of work

- Local AI: inference integrations, model routing, and workflow automation
- Browser tools: extensions, audio capture, playback, and recording
- Media systems: processing, streaming, transcription, and creative utilities
- Self-hosted apps: service deployment, persistence, and recovery
- Interactive software: desktop tools, chat integrations, and browser experiences

### Technologies

Python · JavaScript / TypeScript · Electron · Docker · SQLite  
FFmpeg · Web Audio · GPU inference

### Approach

Build for real use. Keep setup understandable.  
Make failures recoverable. Verify the complete workflow.

For questions, bug reports, or suggestions, use the relevant
repository's issues or discussions.
